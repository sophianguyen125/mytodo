# Mytodo

A calm, simple to-do app for planning your days. It runs in the browser, so there is nothing to install.

**Open the app:** https://sophianguyen125.github.io/mytodo

Your tasks are saved only in your own browser. Nobody else can see them.

## Features

- **Day planning:** Pending (overdue), Today, Tomorrow, the next days and Later
- **Inbox** for tasks without a day
- **Categories** with pastel colors and sub-categories (e.g. University › courses)
- **Task details:** description, sub-tasks with a progress ring, deadline and priority
- **AI box:** turn a list into tasks with the help of claude.ai (free, copy and paste)
- Drag and drop, undo (⌘Z) and redo (⌘⇧Z), light and dark mode
- Export and import a backup file

## Shortcuts in the task box

| Shortcut | Meaning |
|---|---|
| `/nd` | no date (goes to the Inbox) |
| `/tmr` | tomorrow |
| `/15.11` or `/15/11` | on 15 November |
| `/fri` | next Friday (`/mon` … `/sun`) |
| `/dl 20.11` | deadline on 20 November |
| `!` `!!` `!!!` | important, very important, most important |
| `/category` | add a category, e.g. `/shopping` (type `/` to see suggestions) |

Example: `Read chapter 3 /tmr !! /university /dl 20.11`

## Install it like an app

- **Safari (Mac):** File → Add to Dock
- **Chrome, Edge or Brave:** click the install icon in the address bar
